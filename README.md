# قارئ الفواتير

تطبيق ويب مجاني يقرأ الفواتير (تصوير بالكاميرا أو رفع صورة/PDF) ويستخرج بياناتها الأساسية:
المورّد، الرقم الضريبي، رقم الفاتورة، التاريخ، البنود، المجموع قبل الضريبة، الضريبة، الإجمالي، العملة.

- كل المعالجة داخل المتصفح: لا خوادم، لا اشتراكات، ولا تُرسل الفاتورة إلى أي جهة.
- يقرأ رمز QR الخاص بهيئة الزكاة (TLV) فيعطي البائع والرقم الضريبي والتاريخ والإجمالي والضريبة بدقة.
- قراءة النص: Tesseract.js (عربي + إنجليزي). ملفات PDF الرقمية: يُقرأ نصها مباشرة عبر PDF.js.
- شاشة مراجعة: صورة الفاتورة بجانب الحقول القابلة للتعديل، مع تنبيهات عند عدم تطابق المبالغ أو خطأ صيغة الرقم الضريبي.
- رفع عدة فواتير دفعة واحدة: تُقرأ واحدة تلو الأخرى وتظهر في قائمة مع حالة كل فاتورة.
- اختيار مجلد كامل (زر «اختيار مجلد كامل» أو سحب المجلد): تُقرأ كل الصور وملفات PDF داخله وداخل مجلداته الفرعية.
- جدول ملخص الفواتير: المورّد، الرقم الضريبي، الرقم، التاريخ، الضريبة، الإجمالي، الملاحظات (تنبيهات تلقائية + ملاحظتك)، وأزرار اعتماد وحذف، مع تصفية «بانتظار الاعتماد / معتمدة». الحالة والملاحظات تُصدَّر مع Excel و CSV.
- ملف البيانات المرجعية (Excel): زر «تحميل ملف البيانات» يقرأ أوراق SuppliersT و ProjectsT و ProductsT و SupplierProductT (و InvoiceT إن وُجدت) داخل المتصفح فقط، فيطابق المورّد بالرقم الضريبي (VATID، أول 10 أرقام) أو بالاسم، ويعرض قائمة منسدلة للمشاريع الفعالة (ProjectStatus = True) وللمنتجات المرتبطة بالمورّد، وينبّه إن كانت الفاتورة مسجلة سابقًا في InvoiceT.
- تصدير VatReport بنفس أعمدة الورقة: InvoiceNo, SupID, ProjectID, Date, Invamount (الإجمالي شامل الضريبة), invVat.
- تنبيه الفواتير المكررة: إذا تكررت فاتورة بنفس المورّد (الرقم الضريبي أو الاسم) ونفس الرقم والتاريخ تُعلَّم «مكررة» في القائمة وشاشة المراجعة.
- تصدير إلى Excel (ورقتان: الفواتير والبنود، من اليمين لليسار) و CSV يفتح بالعربي في Excel.
- الأرقام الهندية (٠١٢٣٤٥٦٧٨٩): مصنّف صغير خاص بها يعمل داخل المتصفح (`digits.js` + `vendor/digits-model.json`)،
  مع تصحيح المبالغ بالحساب (المجموع + الضريبة = الإجمالي) عند الالتباس.

## التشغيل
الصفحة ملفات ثابتة فقط. للنشر مجانًا على GitHub Pages:
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتوى هذا المجلد كما هو.
2. Settings ← Pages ← Source: Deploy from a branch ← main / root.
3. افتح الرابط من الجوال، واستخدم زر «تصوير بالكاميرا».

للتجربة على الكمبيوتر: `python3 -m http.server` داخل المجلد ثم افتح http://localhost:8000
(فتح index.html مباشرة بدون خادم لا يعمل بسبب قيود المتصفح).

## المكتبات (كلها مجانية ومفتوحة المصدر)
Tesseract.js (Apache-2.0)، jsQR (Apache-2.0)، PDF.js (Apache-2.0)، بيانات اللغة tessdata_best و tessdata_fast/script/Arabic (Apache-2.0).
مصنّف الأرقام دُرّب على خطوط Google Fonts المجانية (OFL)؛ أدوات التدريب في مجلد `tools/`.
